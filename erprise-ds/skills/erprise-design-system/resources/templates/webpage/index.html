Preguntas Frecuentes

¿Tienes dudas? Te respondemos

¿Necesito hardware especial para usar Erprise Attendance?
No. El reloj checador funciona en cualquier navegador web moderno. Para reconocimiento facial solo necesitas una cámara web estándar — no se requiere hardware biométrico propietario. Si deseas biometría dactilar, soportamos lectores Digital Persona U.are.U con un agente local ligero.
¿Cómo funciona el registro desde Telegram?
Tus colaboradores en campo se vinculan una sola vez mediante un código OTP o QR. Después, abren la MiniApp directamente dentro de Telegram para registrar entrada, descanso y salida — con selfie verificada por reconocimiento facial y ubicación GPS. No necesitan descargar ni instalar ninguna aplicación adicional.
¿Cumple con la Ley Federal del Trabajo de México?
Sí. El sistema calcula automáticamente los días de vacaciones según el Artículo 76 reformado (Vacaciones Dignas), incluyendo la progresión por antigüedad y el consumo FIFO de periodos. También gestiona permisos con y sin goce de sueldo e incapacidades IMSS con integración automática en el cierre de asistencia.
¿Puedo administrar la estructura de mi Organización?
Sí. Erprise Attendance tiene una arquitectura que le permite reproducir la estructura de departamentos, puestos las jerarquías entre ellos, turnos, políticas y configuraciones de módulos.
¿Qué tipo de turnos soporta el sistema?
Soportamos tres tipos: Fijos (horario fijo con tolerancia de retardo), Flexibles (meta de horas sin horario fijo — ideal para oficinas con horarios escalonados) y Rotativos N×M (N días de trabajo seguidos de M días de descanso, con cuadrillas y fecha ancla — ideal para industria, hospitales, seguridad y guardias 24/7).
¿Cómo funciona el anti-spoofing del reconocimiento facial?
El sistema utiliza un modelo de IA que analiza la textura y profundidad de la imagen en tiempo real para detectar si se está presentando un rostro real o una fotografía/pantalla. Todo el procesamiento se realiza en el servidor sin enviar datos biométricos a terceros, garantizando privacidad y cumplimiento normativo.
¿Puedo solicitar una demo antes de contratar?
Sí. Ofrecemos una demo personalizada donde le mostramos el sistema en vivo con datos de ejemplo. Contáctenos por el formulario o por WhatsApp y agendamos una sesión sin compromiso.
¿Dónde se alojan mis datos?
Tus datos se almacenan en servidores seguros y bases de datos cifradas en la nube.
